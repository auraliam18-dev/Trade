# Hamid Crypto Futures Signal Room

پنل یکپارچه اسکن سیگنال فیوچرز و Paper Trading. موتور فقط از کندل‌های بسته‌شده استفاده می‌کند تا خروجی در زمان تشکیل کندل repaint نشود.

## اجرا

```bash
python3 03_backend_signal_server_20260610_002822_IRST.py --host 127.0.0.1 --port 8765
```

سپس آدرس <http://127.0.0.1:8765> را باز کنید. برای اجرای پنل بدون اسکن خودکار:

```bash
python3 03_backend_signal_server_20260610_002822_IRST.py --no-auto-scan
```

تنظیمات ریسک و منابع داده با متغیرهای محیطی بالای فایل Python قابل پیکربندی هستند. معاملات واقعی به‌صورت پیش‌فرض و عمدی غیرفعال است.
